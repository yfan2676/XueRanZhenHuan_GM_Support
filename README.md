# 血染钟楼 · 血战甄嬛传 —— 说书人（GM）辅助工具

为《血染钟楼》(Blood on the Clocktower) 自制 Mod「血战甄嬛传 4.2 最终版」提供说书人辅助的**浏览器端应用**。

## 文档

- [docs/rules.md](docs/rules.md) —— 完整角色规则转录 + 官方规则映射 + 边界情况裁定
- [docs/decision_maps.md](docs/decision_maps.md) —— 说书人决策流程图（夜晚结算、处决流程、恶魔更替等）
- `game_rules.jpg` —— 原始规则图
- [docs/demo.mp4](docs/demo.mp4) —— 演示录屏（1920×1168，约 2 分半），两段：
  - 说书人助手：8 人经典后宫，备局 → 首夜 → 处决皇上 → 皇后继任 → 守护挡刀 → 处决皇后，善良获胜
  - 无说书人模式：7 人建房 → 入座就绪 → 自动发身份 → 夜晚行动 → 举手投票 → 终局身份公开

## 开发环境

使用 [uv](https://docs.astral.sh/uv/) 管理，Python 3.12：

```bash
uv sync          # 安装依赖
uv run main.py   # 启动开发服务器 → http://127.0.0.1:8000
```

## 公网访问（Cloudflare Tunnel）

不需要公网 IP、不用做端口映射：`cloudflared` 从本机主动向 Cloudflare 建立出站连接，NAT / CGNAT 后面也能用。

```bash
cp .env.example .env                 # 填入 GM_PASSWORD，任意字符串即可
uv run main.py                       # 本机 8000 端口
cloudflared tunnel --url http://localhost:8000   # 输出一个 https://xxx.trycloudflare.com
```

把这个网址和口令一起发给朋友即可。注意：

- **必须设置 `GM_PASSWORD`**，否则所有页面与接口对全网开放 —— `/api/games` 会列出全部历史对局，`/api/rooms/{rid}/view?name=X` 会把 X 的私密身份返回给任何人。
- 口令只挡外人，**挡不住同局玩家互相偷看身份**（身份仍以玩家名标识）。
- 关掉 `cloudflared` 网址即失效；`--url` 形式每次重启地址都会变，想要固定域名需绑定自己的域名。
- 笔记本关机 / 休眠则服务中断，对局数据本身仍留在 `data/games.json`，重启后自动恢复。

## 目录结构

- `app/` —— FastAPI 后端：`roles.py` 角色目录、`setups.py` 预设板子与半随机分配、`engine.py` 游戏引擎（夜晚结算/白天/投票/胜负）、`auto.py` 无说书人模式（房间/大厅/自动结算）、`store.py` 对局存储（JSON 持久化到 `data/`）、`main.py` API
- `static/` —— 前端单页应用（原生 JS）
  - `index.html` + `app.js` —— 说书人（GM）助手（圆桌视图；窄屏 ≤980px 自动切换为手机版布局，见下）
  - `play.html` + `play.js` —— 无说书人模式玩家端（每人一台设备，手机可用）
  - `static/img/roles/<角色id>.jpg` —— 角色画像（圆形裁切显示，直接替换同名文件即可换图；缺图时自动隐藏不影响布局）

## 手机上当说书人

说书人助手按屏幕宽度（CSS 像素，与手机分辨率/DPI 无关）自适应，两档断点：

**≤980px** —— 圆桌 640px + 侧栏 280px 已经并排放不下，整体换成卡片布局：

- **环形圆桌**：角色分配 / 白天视图把座位摆在网格的四条边上（跑道形），中间留一张小桌子显示预设与配置。1 号在顶边正中、顺时针绕一圈，与电脑端圆桌方向一致，邻座关系一眼可见。列数按可用宽度算（手机 3 列、平板 5~6 列），行数由人数推出；环上多出来的空位留在底边正中
- 录入姓名不走环形，改为「序号 + 输入框」一行一位（按宽度自动分列），窄输入框不利于打字；输入框 16px 以避免 iOS 聚焦时自动放大页面
- 白天/夜晚把操作面板挪到座位上方，提名、入夜、当前夜晚行动一进页面就够得着
- 选中座位后自动把右侧详情滚进视野，按钮最小点击高度 40px

**≤700px** —— 再收紧留白，角色选择、提名、投票等弹窗改为底部抽屉，单手可点。

**>980px（笔记本/桌面）保持原来的圆桌视图，未做任何改动。**

## 无说书人模式（机器人担任 GM）

浏览器打开 `/play.html`：创建房间（只选人数）→ 把房间号告诉朋友 → 各自入座、就绪后自动随机板子并发放身份。

- 每名玩家一个私人屏幕：角色卡、邪恶阵营互认、夜晚行动、白天技能、提名与不记名举手投票（含幽灵票）
- 白天投票票型保密：只同步「已表态 N/总数」与还没投的人，全员投完后一次性公开赞成/反对名单并立即结算（公开前可改票）
- 夜晚全员提交行动后机器人按规则自动结算：死亡链、守护、反杀、继任、醉/毒（醉/毒玩家收到的情报由机器人伪造）
- 原需说书人裁定处自动随机决定（宝宝类型、太后死亡数等）；属于玩家的决定（年羹尧带人、太上皇传位）弹给对应玩家
- 公开信息（死亡、处决、检举、投票结果）广播给全员；私密情报只发给本人；终局公开全部身份与机器人隐藏记录
- 白天无人被处决时，过半存活玩家点「提议入夜」即可收灯
- 断线重连：重新输入房间号，从名单里选回自己的名字即可（私人局，约定不冒名）
